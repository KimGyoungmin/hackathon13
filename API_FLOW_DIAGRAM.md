## 📱 1. 초기 로딩 플로우

```
사용자 접속 (http://localhost:5173)
    │
    ▼
Frontend 시작
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│ 1. GET /api/filters                                         │
│    - 지역 목록 조회                                         │
│    - 카테고리 목록 조회                                     │
│    - 연도 목록 조회                                         │
│    - 응답: {data: {regions: [...], categories: [...], years: [...]}, success: true} │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│ 2. GET /api/festivals                                       │
│    - 전체 축제 목록 조회                                    │
│    - 기본 필터 적용                                         │
│    - 응답: {data: [...], total: 520, success: true}       │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│ 3. Kakao Map API 초기화                                     │
│    - 지도 컨테이너 생성                                     │
│    - 전라남도 중심 좌표 설정 (34.8679, 126.9910)          │
│    - 마커 클러스터링 설정                                   │
└─────────────────────────────────────────────────────────────┘
    │
    ▼
대시보드 렌더링 완료
```
